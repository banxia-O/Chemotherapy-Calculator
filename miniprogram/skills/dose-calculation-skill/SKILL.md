# 化疗剂量计算 Skill

本 Skill 用于把用户自然语言中的参数转化为结构化输入，并调用确定性计算接口完成化疗剂量核对。

## 能力范围

- calculateBSA：身高 cm + 体重 kg → BSA，使用 Mosteller 公式。
- calculateDoseByBSA：BSA + 标准剂量 mg/m² → 实际剂量 mg。
- calculateCarboplatinDose：年龄、性别、体重、血肌酐、目标 AUC → 卡铂剂量。
- calculateS1Dose：BSA → 替吉奥（S-1）常用 bid 分档。

## 工作流

1. 用户只给身高体重时，调用 calculateBSA。
2. 用户给出「药物 + mg/m² + 身高体重」时，先算 BSA，再调用 calculateDoseByBSA。
3. 用户给出「卡铂 AUC」时，必须确认年龄、性别、体重、血肌酐和肌酐单位。默认接口仅接受 μmol/L。
4. 用户问替吉奥/S-1 分档时，必须先获得 BSA 或身高体重；无 BSA 时先算 BSA。
5. 缺少关键参数时先追问，不要自行假设。

## 禁止事项

- 禁止用模型心算替代接口计算。
- 禁止根据癌种或病情自行推荐化疗方案。
- 禁止把计算结果表述为正式医嘱。
- 禁止编造患者参数或药品剂量。

## 结果表达

结果必须包含：
- 输入参数摘要。
- 使用公式。
- 计算结果。
- 是否需要按医院取整规则处理。
- 安全提醒和免责声明。
